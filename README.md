
# 📚 Biblioteca Digital Acessível

## Sobre o projeto

A Biblioteca Digital Acessível é um projeto desenvolvido com HTML5 e CSS3.

O objetivo é apresentar livros e materiais educativos de maneira simples, organizada e acessível.

A página possui seis livros fictícios, capas ilustrativas, informações dos autores e categorias.

O projeto foi desenvolvido pensando na facilidade de leitura e navegação de diferentes usuários.

## Tecnologias utilizadas

- HTML5
- CSS3
- GitHub
- GitHub Pages

## Livros cadastrados

1. O Mundo da Tecnologia
2. Histórias para Imaginar
3. Descobrindo as Ciências
4. Matemática no Dia a Dia
5. Viagem pela História
6. Aprendendo a Crescer

## Práticas de acessibilidade

- Títulos organizados hierarquicamente.
- Textos curtos e objetivos.
- Fonte de fácil leitura.
- Contraste adequado.
- Capas com descrições alternativas.
- Botões com nomes claros.
- Espaçamento adequado.
- Menu de navegação organizado.
- Layout responsivo.
- Navegação pelo teclado com foco visível.
- Poucos elementos visuais desnecessários.

## Objetivo

Criar uma biblioteca digital que facilite o acesso
a materiais educativos e incentive a leitura.
